# Lizenz

## Inhalte des Blogs (Texte, Bilder, Grafiken)

Sofern nicht anders angegeben, sind alle Texte, Grafiken und Bilder auf dieser Seite von mir selbst erstellt und stehen unter der Lizenz

**[Creative Commons Namensnennung 4.0 International (CC BY 4.0)](https://creativecommons.org/licenses/by/4.0/deed.de)**

Sie dürfen die Inhalte teilen und bearbeiten, auch kommerziell, wenn Sie dabei

- mich als Urheber nennen: **Cedric Wünsch**,
- einen Link auf die Quelle angeben (diese Seite),
- einen Link auf die Lizenz angeben,
- kenntlich machen, ob Sie Änderungen vorgenommen haben.

Beispiel für eine korrekte Namensnennung:

> „Titel des Beitrags“ von Cedric Wünsch, `https://gameblog.micedric.dpdns.org/`, Lizenz: CC BY 4.0

Die Lizenz gilt nicht für Inhalte Dritter. Das betrifft z. B. Logos, Marken und Screenshots fremder Software. Dafür gelten die Rechte der jeweiligen Inhaber.

## Quellcode des Projekts

Für den Quellcode im GitHub-Repository gilt die Lizenz, die im Repository in der Datei `LICENSE` angegeben ist. Sie ist maßgeblich und kann von der Lizenz der Blog-Inhalte abweichen.
